RockerStore API · Documentação de desenvolvimento. A autenticação utiliza cookies de sessão do Laravel Sanctum, não token Bearer. No Try it out, o navegador envia os cookies deste host. Antes de POST/PUT/PATCH/DELETE, a interface solicita /sanctum/csrf-cookie e envia X-XSRF-TOKEN. Primeiro execute POST /auth/login para acessar operações protegidas. Abrir OpenAPI YAML.
